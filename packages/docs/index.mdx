Cognitio Agent SDK gives your JavaScript or TypeScript application an agent loop: a model chooses a tool, receives its result, and continues until the task is complete. You choose the model, instructions, tools, and permissions.

It is **built on OpenCode** and includes a matching local runtime. Install one npm package; you do not need to install or launch a separate CLI.

## Start with a working agent

The [quickstart](/quickstart) takes you from an empty directory to a running agent using Node.js and a provider API key.

```js
import { Agent, shutdown } from "cognitio-agent-sdk"

const agent = new Agent({
  model: "openai/gpt-4.1-mini",
  instructions: "Explain software concepts in plain language.",
  disallowedTools: ["*"],
  maxTurns: 3,
})

try {
  const result = await agent.run("What is an agent tool loop?")
  if (result.isError) throw new Error(`Agent stopped: ${result.subtype}`)
  console.log(result.text)
} finally {
  await agent.close().finally(() => shutdown())
}
```

This example uses `OPENAI_API_KEY` from your environment and disables tools for its first text-only response. The quickstart includes installation, credentials, the run command, and expected output.

## Choose an entry point

Start with **`Agent`**. It holds reusable configuration; `agent.run()` completes one task, and `await agent.createSession()` creates a conversation. Use **`query()`** when you want one streamed task without managing an Agent object. Use **`createAgentClient()`** when your application needs direct ownership of the runtime and its sessions.

All three use the same runtime. Local execution starts with isolated configuration and state by default. There is no isolation flag to enable. See [runtime defaults](/defaults-and-isolation) when you need custom credentials, persistent state, or host configuration.
