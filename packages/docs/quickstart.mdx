## 1. Install

Use Node.js 22 or newer, or Bun 1.3.11 or newer, on a [supported platform](/installation).

```sh
npm install cognitio-agent-sdk
```

Keep optional dependencies enabled: they contain the runtime binary for your platform. You do not need a separate runtime installation.

## 2. Configure a provider

Set an API key in your shell. For the example below:

```sh
export ANTHROPIC_API_KEY="your-api-key"
```

For OpenAI, set `OPENAI_API_KEY` and use a compatible `openai/<model>` ID. Provider keys are forwarded through the SDK's explicit environment policy; see [credentials and isolation](/defaults-and-isolation).

## 3. Create `agent.mjs`

```js
import { Agent, shutdown } from "cognitio-agent-sdk"

const agent = new Agent({
  model: "anthropic/claude-sonnet-4-5",
  instructions: "Answer the user's question in one paragraph.",
  maxTurns: 4,
  maxBudgetUsd: 1,
  disallowedTools: ["*"],
})
try {
  const result = await agent.run("Explain how an agent uses a tool.")
  if (result.isError) throw new Error(`Agent ended: ${result.subtype}`)
  console.log(result.text)
  console.log({ cost: result.totalCostUsd, usage: result.usage })
} finally {
  await agent.close().finally(() => shutdown())
}
```

```sh
node agent.mjs
```

`disallowedTools: ["*"]` disables tools for this text-only example. Remove that denylist and set a nonempty `allowedTools` list when the agent should use selected tools. An empty `allowedTools` list does not disable tools. Budget accounting depends on reported usage and catalog pricing; a model call can exceed the threshold before the runtime checks it.

## 4. Stream the answer

```js
import { query, shutdown } from "cognitio-agent-sdk"

try {
  for await (const message of query({
    prompt: "Explain an agent tool loop.",
    options: { model: "anthropic/claude-sonnet-4-5", disallowedTools: ["*"] },
  })) {
    if (message.type === "assistant") console.log(message.text)
    if (message.type === "result") console.log(message.result.subtype)
  }
} finally {
  await shutdown()
}
```

`query()` closes its private Agent and session handle when the stream finishes or you break from the loop. The default process-wide runtime remains available until `shutdown()`. Call `shutdown()` when the application is finished with all facade-owned runtimes, not after each request in a shared service. For conversations, create a [session](/concepts/sessions); each `Agent.run()` starts a fresh session.
