This definition is generated from the same source as the SDK. Protocol types describe the runtime HTTP API; prefer the high-level SDK for session ownership and callbacks.

```ts
export type ServerConfig = {
  /**
   * Port to listen on
   */
  port?: number
  /**
   * Hostname to listen on
   */
  hostname?: string
  /**
   * Enable mDNS service discovery
   */
  mdns?: boolean
  /**
   * Custom domain name for mDNS service (default: cognitio.local)
   */
  mdnsDomain?: string
  /**
   * Additional domains to allow for CORS
   */
  cors?: Array<string>
}
```
