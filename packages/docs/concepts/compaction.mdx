---
title: "Context compaction"
description: "Control summaries and preserve important context."
---
The runtime compacts long conversations near the model's context limit. Configure it per session:

```ts
const agent = new Agent({
  compaction: { auto: true, includeFiles: false },
  hooks: {
    PreCompact: [() => ({ customInstructions: "Preserve decisions, owners and open questions." })],
  },
})
```

`includeFiles: false` avoids a coding-oriented file/directory section. Neutral sessions use a general-purpose summary template. `compaction.auto: false` disables automatic compaction for that session; it does not disable explicit compaction.

```ts
const summary = await session.compact({
  customInstructions: "Keep the acceptance criteria verbatim.",
})
console.log(summary.compactionId, summary.summaryText)
```

`compact()` waits for the runtime compaction boundary and returns its ID, token count, preserved message IDs and summary text when available. A `model` override selects the summary model for that call.

`PreCompact` can add instructions. `PostCompact` reports outcome and preserved-message metadata. Multiple pre-compaction instructions are joined in order. An explicit runtime `agents.compaction` definition customizes the helper agent; `agents.title` customizes title generation if you enable it.

When `checkpointing.beforeCompaction` is enabled, the boundary records the corresponding file checkpoint. A summary is still lossy context management; use durable application storage for records that must never be summarized away.
