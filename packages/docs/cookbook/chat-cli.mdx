Use `examples/01-chat/` for a minimal application built with the published `cognitio-agent-sdk` package. The project includes its own `package.json`, npm lockfile, environment template and complete `index.mjs`; it does not need the monorepo's Bun install or a runtime build.

## Run the project

From the repository root, run the commands below. If you copied the example into another directory, enter that directory first and omit the `cd` line.

```sh
cd examples/01-chat
npm ci
cp .env.example .env
# Set OPENAI_API_KEY in .env, then:
npm start
```

Use Node.js 22 or newer. On PowerShell, replace `cp .env.example .env` with `Copy-Item .env.example .env`. The default model is `openai/gpt-4.1-mini`; change `COGNITIO_MODEL` and the matching provider credential together. Keep `.env` out of Git. The README in each project lists its configuration and expected output.

## The agent loop

The full project creates an `Agent`, supplies a small turn and cost budget, then closes it in `finally`. Its central operation is:

```js
const result = await agent.run("Explain what an agent SDK does in two sentences.")
if (result.isError) throw new Error(`Agent ended: ${result.subtype}`)
console.log(result.text)
```

This is an excerpt using the `agent` created in `index.mjs`. `Agent.run()` collects the response and returns a terminal result; it does not print token deltas. Each call starts a fresh session. For streaming, use [streaming and cancellation](/concepts/streaming). For a conversation, use the [session memory recipe](/cookbook/session-memory).

`disallowedTools: ["*"]` keeps this application text-only. An empty `allowedTools` array does not disable tools. The result text can vary between runs. A successful run prints a nonempty answer; setup or unsuccessful terminal results exit with an error. Budget limits use reported usage and model pricing, so they are not prepaid spending caps.
