## Run a downloaded project

After copying one of the linked project directories, open a terminal in that directory:

```sh
npm ci
```

Copy `.env.example` to `.env`, then replace the API-key placeholder. In a Unix shell:

```sh
cp .env.example .env
```

On PowerShell:

```powershell
Copy-Item .env.example .env
```

The default configuration uses `openai/gpt-4.1-mini` and `OPENAI_API_KEY`. Model access depends on your provider account. Keep `.env` out of Git. After setting the key, run:

```sh
npm start
```

The programs make real model requests and can incur provider charges. They reject unsuccessful results and close the runtimes they own. Their estimated cost limits are not provider billing caps. Each recipe explains its output and what to change next.
