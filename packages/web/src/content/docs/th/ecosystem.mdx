ชุดโครงการชุมชนที่สร้างขึ้นบน Cognitio

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Cognitio ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-cognitio](https://github.com/awesome-cognitio/awesome-cognitio) และ [cognitio.cafe](https://cognitio.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
