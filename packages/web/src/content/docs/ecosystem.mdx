A collection of community projects built on Cognitio.

Want to add your Cognitio related project to this list? Submit a PR.

You can also check out [awesome-cognitio](https://github.com/awesome-cognitio/awesome-cognitio) and [cognitio.cafe](https://cognitio.cafe), a community that aggregates the ecosystem and community.
