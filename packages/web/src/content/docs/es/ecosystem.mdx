Una colección de proyectos comunitarios construidos en Cognitio.

:::note
¿Quieres agregar tu proyecto relacionado con Cognitio a esta lista? Envíe un PR.

También puedes consultar [awesome-cognitio](https://github.com/awesome-cognitio/awesome-cognitio) y [cognitio.cafe](https://cognitio.cafe), una comunidad que agrega el ecosistema y la comunidad.
